# Langeweile-Gaming Launcher - Downloads

Aktuelle Version: **3.1.0** (Stand 11.11.2026)

- **Installer:** https://github.com/solutions-0926/LangeweileLauncher-Release/releases/latest/download/LangeweileLauncherSetup.exe
- **Portable (ZIP):** siehe [Releases](https://github.com/solutions-0926/LangeweileLauncher-Release/releases/latest)

Gibt es eine neue Version, zeigt der Launcher oben rechts den Knopf "Update installieren".
Voraussetzung: Windows 10 (ab Version 1903) oder Windows 11, Mitgliedschaft auf dem Langeweile-Gaming-Discord.
Es wird nichts zusaetzlich installiert - der Launcher nutzt das .NET Framework 4.8, das zu Windows gehoert.

Dieses Repository enthaelt nur die fertigen Downloads; der Quellcode wird
getrennt gepflegt. Fehler bitte im Launcher unter "Bugtracker" oder auf dem
Discord melden.
